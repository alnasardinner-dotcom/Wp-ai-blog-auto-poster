# 🚀 WordPress Rank Math AI Content Generator & Auto-Publisher Tool

আপনার ব্লগ সাইটের জন্য একটি পূর্ণাঙ্গ **AI Content Generator & Auto-Publisher Tool**।

## 🌟 বৈশিষ্ট্যসমূহ (Features)

1. **Rank Math SEO Compliant**:
   - **Title**: প্রধান (Focus) কীওয়ার্ড টাইটেলের শুরুতে থাকে।
   - **Meta Description**: প্রধান কীওয়ার্ড মেটা ডেসক্রিপশনের শুরুতে থাকে।
   - **Rank Math Meta Fields**: `rank_math_focus_keyword`, `rank_math_title`, `rank_math_description` ওয়ার্ডপ্রেস মেটা ফিল্ডে যুক্ত হয়।
2. **EEAT & GEO Optimized**:
   - Google EEAT (Experience, Expertise, Authoritativeness, Trustworthiness) ও GEO ফ্রেন্ডলি রাইটিং।
   - **Key Takeaways Box** এবং স্ট্রাকচার্ড কনটেন্ট।
3. **Table of Contents (TOC)**:
   - অটোমেটিক TOC যা আর্টিকেলের H2 সেকশনগুলোতে ক্লিকযোগ্য অ্যাঙ্কর প্রদান করে।
4. **FAQ Section**:
   - প্রাসঙ্গিক FAQ প্রশ্নের উত্তর ও ক্লিন HTML স্ট্রাকচার।
5. **Internal Linking Assistant**:
   - আর্টিকেলের ভেতরে কোন কোন কাস্টম বা LSI কীওয়ার্ডগুলোতে ইন্টারনাল লিংক বসানো যাবে, তার সাজেশন ও অ্যাঙ্কর টেক্সট হাইলাইট করে।
6. **Pillar & Cluster Support**:
   - Pillar Content বনাম Supporting/Cluster Content নির্বাচন করার সুযোগ।
7. **Multi-AI & 2026 Niche Search Intent Intelligence**:
   - 2026 সালের হাই-ডিমান্ড সাব-টপিক ও নিচ রিসার্চ।
   - Google Search & Google AI Overviews (GEO) রেজাল্ট ও ইউজার ইনটেন্ট।
   - Real users ChatGPT, Perplexity.ai, এবং Claude-এ কি ধরণের প্রম্পট ও সার্চ কোয়েরি ব্যবহার করে তার পূর্ণাঙ্গ অ্যানালাইসিস।
8. **1-Click WordPress Auto-Publish**:
   - ওয়ার্ডপ্রেস REST API দিয়ে ১-ক্লিকে পোস্ট জেনারেট করে সোজাসুজি **Draft** বা **Publish** করা যায়।

## 🛠️ ব্যবহার করার নিয়ম (How to Run)

### Step 1: ডিপেন্ডেন্সি ইনস্টল করা
পাওয়ারশেল (PowerShell) বা টার্মিনালে প্রজেক্ট ফোল্ডারে গিয়ে কমান্ডটি দিন:
```bash
pip install -r requirements.txt
```

### Step 2: Streamlit অ্যাপ রান করা
```bash
streamlit run app.py
```

### Step 3: ওয়ার্ডপ্রেস কানেকশন সেটআপ (Sidebar)
1. আপনার **Gemini API Key** দিন।
2. আপনার **WordPress Site URL** দিন (যেমন: `https://myblogsite.com`)।
3. আপনার **WP Username** দিন।
4. ওয়ার্ডপ্রেস ড্যাশবোর্ড থেকে **Application Password** তৈরি করুন (`Users -> Profile -> Application Passwords`) এবং সেটি অ্যাপের সাইডবারে দিন।
5. **Test WP Connection** বাটনে ক্লিক করে কানেকশন নিশ্চিত করুন।

### Step 4: কন্টেন্ট জেনারেট ও পোস্ট করা
1. **Main Keyword** লিখুন।
2. **Generate AI Content** বাটনে ক্লিক করুন।
3. জেনারেট করা কনটেন্ট, TOC, Meta এবং Internal Link Suggestions প্রিভিউ দেখুন।
4. **Push to WordPress Now** বাটনে ক্লিক করে ১-ক্লিকে ব্লগে আপলোড করুন!
